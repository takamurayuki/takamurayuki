## 🔬 Ongoing Experiment

### React vs Vue vs Svelte — Which framework works best with AI coding agents? 🚧 *In progress*

I'm building **the same app in React, Vue, and Svelte with Claude Code**, using identical specs and prompts, and measuring:

| Metric | What I measure |
| --- | --- |
| ⏱ Development time | Time and number of prompts to reach a working app |
| ✅ Code quality | Lint / type errors and review findings |
| 🧪 Test coverage | Coverage of AI-generated tests |
| 🔧 Maintainability | Effort required for follow-up changes |

📢 Results and a full write-up will be published on [Zenn](https://zenn.dev/taka8823) — coming soon.
